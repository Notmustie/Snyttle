## Brief Description

Is a general-purpose multi-agent AI system designed to collaboratively perform complex research tasks through a coordinated workforce of specialized AI agents. Built using LangGraph, the system employs a Supervisor Agent to plan, delegate, monitor, and coordinate tasks among agents responsible for research, literature retrieval, document-based knowledge retrieval, data analysis, critical evaluation, and report generation. The system integrates external tools such as web and academic search, Retrieval-Augmented Generation (RAG), Python-based data analysis, and persistent memory to provide evidence-backed research outputs. A Streamlit-based interactive interface enables users to monitor agent execution, inspect communication and memory, review results, and intervene through human-in-the-loop controls such as approval, revision, pause, and resume. The proposed system aims to demonstrate how collaborative AI agents can function as an intelligent research workforce capable of dynamically adapting its workflow to different research questions and information requirements.
